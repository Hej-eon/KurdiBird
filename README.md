# KurdiBird

A Kurdish-inspired arcade flight game built with Phaser, TypeScript, and Vite.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Vision

KurdiBird keeps the instantly readable flap-and-dodge loop of a classic arcade game, but gives it a distinct Kurdish visual identity: mountain landscapes, warm textile-inspired details, bilingual-ready UI, and an original sound direction.
